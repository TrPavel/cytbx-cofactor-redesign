# Structures

PDB / CIF / MOL2 / SDF files used as input and output of the design protocol.

## `starting/` — Input models

| File                                       | Description                                                           |
| ------------------------------------------ | --------------------------------------------------------------------- |
| [`cytbx.pdb`](starting/cytbx.pdb)          | X-ray-derived model of CytbX with both b-type heme cofactors bound    |
| [`cytbx_no_heme.pdb`](starting/cytbx_no_heme.pdb) | Apo CytbX (heme cofactors removed) — input scaffold for redesign |
| [`cytbx_znh.pdb`](starting/cytbx_znh.pdb)  | Apo CytbX with one **ZnPPIX** cofactor manually placed in the upper pocket |
| [`cytbx_bcl.pdb`](starting/cytbx_bcl.pdb)  | Apo CytbX with one **BCL** cofactor manually placed in the upper pocket |

## `cofactors/` — Ligand topology and conformer libraries

| File                                              | Description                                                |
| ------------------------------------------------- | ---------------------------------------------------------- |
| [`ZNH.pdb`](cofactors/ZNH.pdb), [`.cif`](cofactors/ZNH.cif), [`.mol2`](cofactors/ZNH.mol2), [`.sdf`](cofactors/ZNH.sdf) | Reference ZnPPIX ligand in four formats (PDB chemical component **ZNH**) |
| [`ZNH_conformers.pdb`](cofactors/ZNH_conformers.pdb) | 50-conformer multi-model PDB generated by the Frog2 web server |
| [`BCL.pdb`](cofactors/BCL.pdb), [`.cif`](cofactors/BCL.cif), [`.mol2`](cofactors/BCL.mol2), [`.sdf`](cofactors/BCL.sdf) | Reference Bacteriochlorophyll A ligand (PDB chemical component **BCL**) |
| [`BCL_conformers.pdb`](cofactors/BCL_conformers.pdb) | 50-conformer multi-model PDB generated by the Frog2 web server |

The conformer libraries are loaded by Rosetta during the `Transform` and `HighResDocker` stages
so the design protocol can sample alternative cofactor geometries inside the binding pocket.

## `top_designs/` — Best-scoring designs

PDB coordinates of the top 5–6 designs per cofactor, extracted from the silent-file output of the
production Rosetta runs.

| Subfolder                  | Contents                                              |
| -------------------------- | ----------------------------------------------------- |
| [`znh/`](top_designs/znh/) | 5 lowest-energy ZnPPIX designs (model 1 → 5)          |
| [`bcl/`](top_designs/bcl/) | 6 lowest-energy BCL designs (model 1 → 5 + alt)       |

File names follow the convention `<SLURM_JOBID>cytbx_<cofactor><array_task_id>_<decoy_index>.pdb`.
Score-vs-RMSD pairs for every decoy are tabulated in [`../data/`](../data/).
